Recar is designed to bridge the gap between Discord Web and a native Linux application. Here are some of its core features.

### Recar Overlay

Recar has a tightly intergrated game overlay implementation that is distro agnostic for Linux.

<video controls muted autoplay loop src="../../src/assets/media/overlay.webm"></video>
> *Recar Overlay on Wayland, KDE Plasma, games in order: ULTRAKILL, Minecraft (1.8.9) w/ Zink, A Hat in Time, Illusion Carnival*

As seen in the video above and below, Recar Overlay can be customized to move sections of the UI to any corner or edge.

<video controls muted autoplay loop src="../../src/assets/media/overlaycustomization.webm"></video>
> *Recar on Wayland, KDE Plasma. Testing version, so may not represent actual featureset.*

Recar implements the [roverpp](https://codeberg.org/TheUnium/roverpp) project, specifically made for Recar Overlay.

#### Support

Recar Overlay is heavily unfinished, however about 95% of Vulkan games (including games running under Proton over DXVK, basically anything that isn't too old) should just work.

Potential troubleshoot options are in [the troubleshooting page](../../reference/troubleshooting) in the event of an issue.

### Better notifications

Recar provides a better notification experience on supported systems, even compared to the Windows Discord client and other Linux clients such as Vesktop.

If **text input** is supported (KDE Plasma, GNOME namely supports this), you can reply directly to a notification from the native UI.

### Screen Sharing Improvements

Recar includes robust support for screen sharing on Wayland and X11, with audio.

<video controls muted autoplay loop src="../../src/assets/media/screenshare.webm"></video>
> *Screensharing on Wayland, in KDE Plasma*

Demonstrated in the video is:

1. Framerate & Resolution controls
2. Selecting one, or multiple sources of audio, or just your entire computer
3. Switch your source for streaming easily
4. Options to prefer high clarity, or smoothness. Generally, Prefer Smoothness is recommended (and is the default because of this) as it suits 99% of use cases. Prefer Clarity has a huge hit on framerate but has exceptional bitrate.

Recar implements the [venmic](https://github.com/Vencord/venmic/) project, notably used in Vesktop for audio streaming.

### Built-in Discord Rich Presence

Recar includes the [dpprpc](https://codeberg.org/TheUnium/dpprpc) project directly in the client, meaning you can immediately start using Discord RPC.

### Custom Ringing Popup

Recar features a specialized "ringing" window that appears when you receive a call. It is styled to be similar to Discord's default UI and uses the color theme you use on your Discord.

<video controls muted autoplay loop src="../../src/assets/media/callwindow.webm"></video>
> *Recar call window changes theme based on Discord theme (old version)*

### Extremely customizable

Recar has Discord Stable, PTB and Canary built into one program. You can switch between them from just a restart, so you essentially have 3 Discords on your computer with Recar. Additionally Recar has modded clients such as Vencord and Equicord built in, allowing for the use of their extremely useful plugins. Recar also adds onto them with its own plugins.
